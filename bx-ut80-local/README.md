# BX UT80 Local — canal de distribuição experimental

Canal separado do catálogo principal, destinado à variante pessoal para LG 50UT8050PSA. O projeto público BX Community Final permanece suspenso. Pacotes experimentais, sem garantia de compatibilidade ou desempenho. Não requer root. Não distribui o repositório de desenvolvimento privado; o IPK contém seu próprio código JavaScript e avisos de licença. Nenhum dado de conta deve ser incluído nos pacotes. Instalação e atualização por iniciativa do usuário no Homebrew Channel.
